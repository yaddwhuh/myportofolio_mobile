Widget Tree adalah struktur data, sesuai dengan namanya, yang berbentuk pohon yang merepresentasikan seluruh susunan UI dalam Flutter app. Di dalam Flutter, hampir seluruh elemen aplikasi adalah widget. 4. Stateless itu immutable dan Stateful itu mutable, lalu Stateful dapat memperbarui tampilan secara dinamis dengan `setState()` dan tidak dengan Stateless. Dari perbedaan tersebut, Stateless lebih cocok digunakan untuk UI yang tidak harus berubah berdasarkan interaksi pengguna, sedangkan Stateful cocok digunakan UI yang harus bereaksi terhadap interaksi pengguna, input formulir, animasi, timer, increment, dll.

5. BuildContext adalah objek yang merepresentasikan lokasi spesifik sebuah widget di dalam widget tree. Objek ini penting karena menjadi penghubung bagi widget untuk mengakses data atau konfigurasi dari widget induk (ancestor) di atasnya tanpa harus mengoper parameter secara manual. Penggunaan di dalam `build()` yaitu untuk mengambil layanan atau konfigurasi dari atas tree seperti `Theme.of(context)`, `MediaQuery.of(context)`, atau `Navigator.of(context)`.

6. Hot reload 'menyuntikkan' perubahan kode ke Dart VM dan membangun ulang tampilan UI secara instan dengan mempertahankan state aplikasi saat ini. Sebaliknya, hot restart mengompilasi ulang seluruh kode Dart dari awal dan mereset semua state kembali ke kondisi awal aplikasi. Hot Restart diharuskan ketika kita mengubah kode di dalam main(), initState(), variabel global/static, definisi enum, atau mengubah StatelessWidget menjadi StatefulWidget (dan sebaliknya), dan Full Restart diharuskan ketika kita menambahkan dependensi atau aset baru (gambar/font) di pubspec.yaml, serta saat mengubah kode native di folder android/ atau ios/.

# Tugas 8

1. `Navigator.push()` menambahkan halaman baru ke atas stack tanpa mengganti halaman yang paling atas, sehingga pengguna bisa menggunakan tombol back untuk kembali. `Navigator.pushReplacement()` mirip push, namun perbedaannya yaitu halaman yang paling atas akan diganti oleh halaman baru sehingga tidak bisa menggunakan tombol back untuk kembali (karena halaman sebelumnya sudah tidak ada). `Navigator.pop()` menghapus halaman paling atas pada stack dan menampilkan halaman paling atas pada stack saat ini. Membuka formPage dari action card menggunakan `Navigator.push()`. Opsi Home pada drawer membawa pengguna ke main screen dengan menggunakan `Navigator.pushReplacement()` menunjuk ke arah `MyHomePage()`, sehingga stack paling atas akan diganti oleh halaman home.

2. `Scaffold` menyediakan kerangka tata letak standar Material Design pada setiap halaman (mengatur area bilah atas, badan halaman/body, dan panel samping), `AppBar` menempatkan judul halaman serta tombol navigasi (seperti ikon menu hamburger untuk membuka drawer atau tombol kembali) di posisi yang tetap di bagian atas layar, sehingga orientasi dan navigasi pengguna konsisten di setiap halaman, dan `Drawer` menyediakan panel navigasi samping yang dapat dibuat sebagai widget terpisah dan dipakai ulang (reusable) di berbagai halaman. Warna utama aplikasi didefinisikan secara terpusat pada `ThemeData` di dalam `MaterialApp`.

3.  Tata letak vertikal berbasis Column di dalam widget Form dipilih karena elemen input formulir memiliki alur pengisian berurutan dari atas ke bawah (satu kolom input per baris). Susunan vertikal ini memudahkan keterbacaan label, kolom isian, serta pesan kesalahan validasi pada layar perangkat bergerak yang memiliki lebar terbatas. Widget pengatur jarak (Padding dan SizedBox) memiliki fungsi yaitu, Padding memberikan ruang batas antara tepi layar dan area formulir agar elemen tidak menempel ke pinggir layar, sedangkan SizedBox memberikan jarak vertikal yang konsisten antar-kolom input. Jarak ini menjaga keterbacaan dan mencegah salah sentuh (mis-tap), terutama ketika teks pesan error muncul di bawah kolom input. Kemudian fungsi Widget Penggulir (SingleChildScrollView atau ListView) yaitu ketika ruang vertikal layar menyempit, misalnya pada ponsel berukuran kecil atau saat papan ketik virtual (on-screen keyboard) muncul dan menutupi hampir separuh layar, widget penggulir memungkinkan seluruh isi formulir digeser (scroll) ke atas dan ke bawah. Tanpa widget penggulir, Flutter akan memunculkan kesalahan RenderFlex overflow dan pengguna tidak dapat menjangkau kolom bagian bawah maupun tombol Simpan.

4. `GlobalKey<FormState>` berfungsi sebagai pengenal unik yang menyimpan referensi ke state internal dari widget `Form (FormState)`, sehingga status formulir dapat diakses dan dikendalikan dari luar pohon widget `Form` (misalnya dari dalam fungsi `onPressed` tombol Simpan). `validate()` adalah metode yang dipanggil melalui `_formKey.currentState!.validate()` ketika tombol Simpan ditekan. Metode ini menjalankan seluruh fungsi validator pada setiap `TextFormField` di dalam Form secara serentak. Jika semua kolom valid (mengembalikan null), `validate()` mengembalikan nilai true agar data dapat diproses; jika ada minimal satu kolom yang tidak valid, `validate()` mengembalikan false dan menghentikan proses penyimpanan. `validator` adalah fungsi pemeriksaan yang dipasang pada setiap `TextFormField` untuk mengevaluasi nilai yang diketik pengguna (String? value) berdasarkan aturan tertentu. Jika nilai tidak memenuhi syarat, validator mengembalikan String berisi pesan error untuk ditampilkan di bawah kolom terkait; jika valid, fungsi mengembalikan null. Salah satu contoh nilai yang ditolak oleh validasi yaitu hanya memberikan spasi dalam isian, dimana hanya memilih jenis input hanya memaksa pengguna untuk menggunakan jenis keyboard yang benar, tetapi tetap bisa diakali dengan misalnya copy-paste. Selain itu, pengguna bisa saja memilih, misalkan tanggal lahir yang tidak valid sehingga tetap diperlukan validator.
